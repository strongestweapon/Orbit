Orbit 0.8.1

• 모든 영상의 파라미터와 이벤트에 기본 OSC 수신 주소를 제공합니다. 씬 이름이 포함된 주소를 복사하거나 수정할 수 있으며, OSC 전체 맵에도 함께 반영됩니다. 수신은 앱 실행 시 자동으로 시작합니다.
• OSC 전체 맵에 이 Mac의 IP, 수신 포트, 공통 출력 IP·포트를 모았습니다. 주소를 정렬하고 입력 범위와 트리거 조건을 표시합니다.
• 외부 신호를 받은 파라미터와 섹션에 수신 표시가 켜집니다. 같은 값이 반복되어도 매번 표시하며, 전체 맵에서 최근 값과 수신 상태를 확인할 수 있습니다.
• 연속값 출력은 같은 OSC 주소에서 연속값 또는 트리거로 선택할 수 있습니다. 트리거 모드는 새 입력마다 Float 1.0을 한 번 보내며, 같은 값이나 0.0을 다시 받아도 실행합니다. 대기 중에는 트리거를 반복 송신하지 않습니다.
• 제어 출력을 OSC로 통일했습니다. 기존 MIDI 출력은 OSC로 이전하고, 기존 센서 연결은 저장된 수신 주소로 옮깁니다. 추가 센서 목록과 중복 설정·제어 버튼을 제거했습니다.
• Pulse Orbit의 조절 항목을 기본 움직임·리듬·궤도·상호작용·색상·출력 신호로 나눴습니다. 주요 파라미터와 트리거는 메인 화면에서 조작하며, 영상 미리보기 공간을 유지합니다.
• 매핑 설정창에서 제목과 닫기 버튼이 잘리던 문제를 수정했습니다. 내용이 길 때는 설정 내용만 스크롤되고 제목과 닫기 버튼은 계속 보입니다.
• Golden Drift의 기본 움직임을 개선하고, 영상 출력과 OSC 상태는 하단 상태 표시줄에 모았습니다.

macOS 14 이상 · Apple Silicon / Intel 공용
설정과 OSC 매핑은 저장됩니다. 공연·설치 운영을 마친 뒤 업데이트하세요. 설치·재실행은 사용자가 승인한 뒤 진행합니다.
