Orbit 0.8.0

• 새로운 실시간 생성 씬 Pulse Orbit을 추가했습니다. 레드·화이트 궤도의 펄스가 중력·관성·리듬·군집 변화에 반응하고, 근접 연결과 교차 섬광·파동을 만듭니다. 점선 대신 굵어졌다 얇아지는 연속선을 사용합니다.
• Pulse Orbit의 ‘라인 추가’ 트리거로 새 궤도를 하나씩 추가합니다. 기본 3 → 4 → … → 10 → 3 순환이며, 최대 개수는 4–10개로 설정할 수 있습니다. 버튼 옆에 현재/최대 개수를 표시합니다.
• 연속값 슬라이더와 트리거 이벤트 버튼을 분리했습니다. 8개 영상에 방전·섬광·수축·궤도 반전 등 개별 이벤트를 제공하며, 이벤트마다 독립적으로 OSC 입력과 MIDI/OSC 출력을 연결합니다.
• 이벤트 수신 모드는 Float 0.5 이상인 메시지마다 실행합니다. 연속 센서값이나 영상 파라미터가 임계값을 통과할 때 이벤트를 실행하도록 설정할 수도 있습니다.
• 이벤트 출력은 발생할 때만 OSC Float 1.0 또는 MIDI CC 0 → 127을 보냅니다. 같은 신호가 반복되어도 매번 실행하며, 대기 중 이벤트 신호를 반복 송신하지 않습니다. 연속값 설정과 연속 출력은 유지됩니다.
• Pulse Orbit의 실제 교차 시점·위치·강도와 근접도를 Live/OSC로 보낼 수 있습니다. 함께 발생하는 교차 값은 OSC bundle로 전달합니다.
• OSC 매핑 창에 연속값/트리거 이벤트 필터를 추가했습니다. 이벤트 입력·출력·시간 설정과 라인 최대 개수는 저장하며, 이전 파라미터 이벤트 설정은 별도 트리거로 이전합니다.

macOS 14 이상 · Apple Silicon / Intel 공용
공연·설치 운영을 마친 뒤 업데이트하세요. 설치·재실행은 사용자가 승인한 뒤 진행합니다.
추가된 궤도 수는 처음부터 재생·씬 재선택·앱 재실행 시 기본 3개로 돌아갑니다. 최대 개수와 OSC 매핑 설정은 보존됩니다.
