Orbit 0.7.0

• LED 출력의 안쪽·바깥쪽 방향을 도면에 맞췄습니다. 각 출력 행의 위쪽은 바깥쪽, 아래쪽은 안쪽입니다. 실시간 영상과 원본 재생에 동일하게 적용됩니다.
• LED 테스트 패턴에 1–5 구간별 고유색과 숫자, 바깥쪽 파랑 띠·안쪽 빨강 띠를 표시합니다. 안쪽·바깥쪽만 따로 확인하는 패턴도 제공합니다.
• OSC 입력과 영상 파라미터 조절값을 실수 0.0–1.0으로 통일했습니다. 트리거는 0.5 이상인 패킷을 받을 때마다 실행하며, 같은 씬도 다시 시작합니다.
• OSC 매핑 창에서 글로벌 동작과 영상별 파라미터 연결을 함께 확인하고 편집할 수 있습니다.
• 출력 모니터와 운영 설정을 기억하며, 저장한 모니터가 없으면 현재 화면으로 대체합니다. 앱 종료 시 출력 창도 함께 닫습니다.
• 별도 출력은 항상 LED 5행 배치를 사용합니다. 전체화면 출력 중 미리보기를 끄는 옵션으로 GPU 부하를 줄일 수 있습니다.
• UI 강조색을 진한 파랑으로 통일하고, 어두운 배경의 버튼 글씨와 아이콘은 흰색으로 바꿔 가독성을 높였습니다.

macOS 14 이상 · Apple Silicon / Intel 공용
