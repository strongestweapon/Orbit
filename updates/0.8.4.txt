Orbit 0.8.4

• 화면 컨트롤, OSC 전체 맵, 실제 수신·송신, 주소 참조표가 하나의 컨트롤 정의를 사용하도록 구조를 통합했습니다. 화면에서 매핑할 수 있는 항목만 전체 맵에 표시하며, 이름·범위·입출력 설정이 함께 반영됩니다.
• OSC 전체 맵을 씬 파라미터·트리거 이벤트·공통 조절로 나눴습니다. Pulse Orbit은 씬 연속값 5개, 트리거 4개, 공통·설치 조절 8개가 입력과 출력 양쪽에 표시됩니다.
• 화면에 없는 내부 시뮬레이션 출력과 동작하지 않는 조절 항목을 제외했습니다. Pulse Orbit의 빈 구간 이동, 원본 동영상의 전체 회전은 더 이상 매핑 대상으로 노출하지 않습니다.
• 실제 화면 컨트롤의 사용자 지정 OSC 주소, 송신 범위, 연속값/트리거 출력 방식과 저장 설정을 유지합니다. 기존 연결을 사용 중인 호환용 파라미터는 화면의 ‘기존 연결’과 전체 맵에 함께 표시합니다.

기존 연결 확인: 화면 컨트롤이 없는 Pulse Orbit 내부 신호인 현재 근접도, 교차 발생·위치·강도, 사건 위치·강도는 이번 버전부터 송신하지 않습니다. 이 출력에 연결한 외부 프로그램은 화면에 있는 파라미터나 출발·돌파·새 궤도·완료 이벤트 출력으로 연결을 조정하세요. 제거된 연결을 다른 동작에 자동으로 재지정하지 않습니다.
